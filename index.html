Soru ve Cevaplar

Soru 1: Tablodaki tüm sütunları ve tüm satırları listeleyecek en temel SQL komutu hangisidir?

Cevap 1: SELECT * FROM Ogrenciler;

Soru 2: Tablodan sadece öğrencilerin Adi ve Soyadi sütunlarını getiren SQL sorgusu hangisidir?

Cevap 2: SELECT Adi, Soyadi FROM Ogrenciler;

Soru 3: Aynı bölüm isminin tekrar tekrar görünmesini engelleyerek her bölümü sadece bir kez listeleyen (tekilleştiren) sorgu hangisidir?

Cevap 3: SELECT DISTINCT Bolum FROM Ogrenciler;

Soru 4: Bölümü 'Bilgisayar' olan öğrencilerin tüm bilgilerini getiren filtreleme sorgusu hangisidir?

Cevap 4: SELECT * FROM Ogrenciler WHERE Bolum = 'Bilgisayar';

Soru 5: Not ortalaması 3.00 veya daha yüksek olan öğrencilerin sadece adını ve not ortalamasını listeleyen sorgu hangisidir?

Cevap 5: SELECT Adi, Not_Ortalamasi FROM Ogrenciler WHERE Not_Ortalamasi >= 3.00;

Soru 6: Bölümü 'Bilgisayar' olan VE şehri 'İstanbul' olan öğrencileri getiren sorgu hangisidir?

Cevap 6: SELECT * FROM Ogrenciler WHERE Bolum = 'Bilgisayar' AND Sehir = 'İstanbul';

Soru 7: Şehri 'Ankara' VEYA 'İzmir' olan öğrencileri listeleyen sorgu hangisidir?

Cevap 7: SELECT * FROM Ogrenciler WHERE Sehir = 'Ankara' OR Sehir = 'İzmir';

Soru 8: Öğrencileri not ortalamasına göre düşükten yükseğe (artan sırada) sıralayarak getiren SQL sorgusu hangisidir?

Cevap 8: SELECT * FROM Ogrenciler ORDER BY Not_Ortalamasi ASC;

Soru 9: Öğrencileri not ortalamasına göre en yüksekten en düşüğe (azalan sırada) sıralayan sorgu hangisidir?

Cevap 9: SELECT * FROM Ogrenciler ORDER BY Not_Ortalamasi DESC;

Soru 10: Doğum yılı 2003 ile 2005 arasında (her iki yıl da dahil) olan öğrencileri filtreleyen en pratik sorgu hangisidir?

Cevap 10: SELECT * FROM Ogrenciler WHERE Dogum_Yili BETWEEN 2003 AND 2005;

Soru 11: İsmi 'A' harfi ile başlayan öğrencileri listeleyen SQL sorgusu hangisidir?

Cevap 11: SELECT * FROM Ogrenciler WHERE Adi LIKE 'A%';

Soru 12: Soyadı 'Kaya' OLMAYAN öğrencileri listelemek için yazılması gereken sorgu hangisidir?

Cevap 12: SELECT * FROM Ogrenciler WHERE Soyadi <> 'Kaya';

Soru 13: Tabloda toplam kaç adet öğrenci (satır) kayıtlı olduğunu hesaplayan sorgu hangisidir?

Cevap 13: SELECT COUNT(*) FROM Ogrenciler;

Soru 14: Tüm öğrencilerin not ortalamalarının genel ortalamasını veren SQL sorgusu hangisidir?

Cevap 14: SELECT AVG(Not_Ortalamasi) FROM Ogrenciler;

Soru 15: Tablodaki en yüksek not ortalamasına sahip değeri getiren SQL fonksiyonu hangisidir?

Cevap 15: SELECT MAX(Not_Ortalamasi) FROM Ogrenciler;

Soru 16: Tablodaki en düşük not ortalamasını listeleyen sorgu hangisidir?

Cevap 16: SELECT MIN(Not_Ortalamasi) FROM Ogrenciler;

Soru 17: Her bölümde kaçar adet öğrenci olduğunu bölüm isimleriyle birlikte listeleyen kümeleme sorgusu hangisidir?

Cevap 17: SELECT Bolum, COUNT(*) FROM Ogrenciler GROUP BY Bolum;

Soru 18: Her şehirden okuyan öğrencilerin not ortalamalarının ayrı ayrı ortalamasını şehir bazında gösteren sorgu hangisidir?

Cevap 18: SELECT Sehir, AVG(Not_Ortalamasi) FROM Ogrenciler GROUP BY Sehir;

Soru 19: COUNT(*) fonksiyonunun ekrana gelen sütun adını geçici olarak 'Toplam_Ogrenci' şeklinde değiştiren takma ad (alias) sorgusu hangisidir?

Cevap 19: SELECT COUNT(*) AS Toplam_Ogrenci FROM Ogrenciler;

Soru 20: Sorgu sonucunda ekrana gelecek yeni sütun başlığının boşluk içerecek şekilde 'Öğrenci Adı' yazmasını sağlayan doğru sözdizimi hangisidir?

Cevap 20: SELECT Adi AS [Öğrenci Adı] FROM Ogrenciler;

Soru 21: Tabloya adı 'Can', soyadı 'Öztürk', bölümü 'Hukuk' olan yeni bir öğrenci ekleyen SQL kayıt komutu hangisidir?

Cevap 21: INSERT INTO Ogrenciler (Adi, Soyadi, Bolum) VALUES ('Can', 'Öztürk', 'Hukuk');

Soru 22: Ogrenci_ID'si 3 olan öğrencinin şehri 'Ankara' iken 'Bursa' olarak değiştirmek (güncellemek) isteyen biri hangi komutu yazmalıdır?

Cevap 22: UPDATE Ogrenciler SET Sehir = 'Bursa' WHERE Ogrenci_ID = 3;

Soru 23: Ogrenci_ID'si 4 olan öğrenci kaydını tablodan tamamen silen SQL sorgusu hangisidir?

Cevap 23: DELETE FROM Ogrenciler WHERE Ogrenci_ID = 4;

Soru 24: Eğer DELETE FROM Ogrenciler; komutu arkasına hiçbir WHERE şartı yazılmadan çalıştırılırsa ne olur?

Cevap 24: Tablodaki tüm öğrenci kayıtları (veriler) silinir ama boş tablo yapısı kalır.

Soru 25: Şehir sütunundaki 'İstanbul' yazan verilerin çıktı ekranında 'İst' olarak görünmesini sağlayan yer değiştirme fonksiyonu hangisidir?

Cevap 25: SELECT REPLACE(Sehir, 'İstanbul', 'İst') FROM Ogrenciler;

Soru 26: Not ortalaması 2.50 ile 3.50 arasında OLMAYAN öğrencileri listelemek için hangi sorgu doğrudur?

Cevap 26: SELECT * FROM Ogrenciler WHERE Not_Ortalamasi NOT BETWEEN 2.50 AND 3.50;

Soru 27: İsminin son harfi 'f' olan öğrencileri (örneğin Elif) listelemek için doğru LIKE kalıbı hangisidir?

Cevap 27: SELECT * FROM Ogrenciler WHERE Adi LIKE '%f';

Soru 28: İçinde 'me' ifadesi geçen öğrencilerin isimlerini listeleyen sorgu hangisidir?

Cevap 28: SELECT * FROM Ogrenciler WHERE Adi LIKE '%me%';

Soru 29: Tablodaki tüm öğrencilerin not ortalamalarının toplam değerini tek bir sonuç olarak veren sorgu hangisidir?

Cevap 29: SELECT SUM(Not_Ortalamasi) FROM Ogrenciler;

Soru 30: Bölümü 'Bilgisayar' olan öğrencilerin not ortalamalarının aritmetik ortalamasını getiren sorgu hangisidir?

Cevap 30: SELECT AVG(Not_Ortalamasi) FROM Ogrenciler WHERE Bolum = 'Bilgisayar';

Soru 31: Her bölümdeki en yüksek not ortalamasını bölüm adıyla listeleyen SQL komutu hangisidir?

Cevap 31: SELECT Bolum, MAX(Not_Ortalamasi) FROM Ogrenciler GROUP BY Bolum;

Soru 32: Uzun tablo ismi olan 'Ogrenciler' tablosuna geçici olarak 'o' lakabını takarak adı sütununu çeken sorgu hangisidir?

Cevap 32: SELECT o.Adi FROM Ogrenciler AS o;

Soru 33: Tüm öğrencileri önce 'Bolum' adına göre (A'dan Z'ye), bölümleri aynı olanları ise kendi içinde 'Not_Ortalamasi'na göre (yüksekten düşüğe) sıralayan sorgu hangisidir?

Cevap 33: SELECT * FROM Ogrenciler ORDER BY Bolum ASC, Not_Ortalamasi DESC;

Soru 34: Not_Ortalamasi alanı boş bırakılmış (Null girilmiş) olan öğrencileri bulup listeleyen doğru SQL koşulu hangisidir?

Cevap 34: SELECT * FROM Ogrenciler WHERE Not_Ortalamasi IS NULL;

Soru 35: Not_Ortalamasi alanı boş bırakılmamış (yani içerisine bir not girilmiş) öğrencileri filtreleyen sorgu hangisidir?

Cevap 35: SELECT * FROM Ogrenciler WHERE Not_Ortalamasi IS NOT NULL;

Soru 36: Tüm öğrencilerin not ortalamasını 0.50 puan yükseltecek şekilde güncelleyen toplu UPDATE sorgusu hangisidir?

Cevap 36: UPDATE Ogrenciler SET Not_Ortalamasi = Not_Ortalamasi + 0.50;

Soru 37: Bölümü 'Makine' olan tüm öğrencileri tablodan tek seferde silen sorgu hangisidir?

Cevap 37: DELETE FROM Ogrenciler WHERE Bolum = 'Makine';

Soru 38: İsminin ikinci harfi 'h' olan öğrencileri (örneğin Ahmet) listemek için hangi LIKE kalıbı kullanılmalıdır?

Cevap 38: SELECT * FROM Ogrenciler WHERE Adi LIKE '_h%';

Soru 39: Doğum yılları benzersiz (tekrar etmeyecek) şekilde toplam kaç farklı doğum yılı olduğunu sayan sorgu hangisidir?

Cevap 39: SELECT COUNT(DISTINCT Dogum_Yili) FROM Ogrenciler;

Soru 40: Bölüm adlarını çıktı ekranında tamamen büyük harfe dönüştürerek listeleyen fonksiyon hangisidir?

Cevap 40: SELECT UPPER(Bolum) FROM Ogrenciler;

Soru 41: Not ortalaması 2.00, 3.00 veya 4.00 değerlerinden herhangi birine tam eşit olan öğrencileri listeleyen en temiz sorgu hangisidir?

Cevap 41: SELECT * FROM Ogrenciler WHERE Not_Ortalamasi IN (2.00, 3.00, 4.00);

Soru 42: Şehri 'İstanbul' OLMAYAN ve bölümü 'Bilgisayar' olan öğrencileri listeleyen sorgu hangisidir?

Cevap 42: SELECT * FROM Ogrenciler WHERE Sehir <> 'İstanbul' AND Bolum = 'Bilgisayar';

Soru 43: Tablonun içindeki tüm verileri silmek ama tablo şemasını (boş tabloyu) veritabanında korumak için hangi komut kullanılır?

Cevap 43: DELETE FROM Ogrenciler;

Soru 44: Bölümü 'Elektronik' olan öğrencilerin not ortalamasını tam olarak 4.00 yapacak şekilde güncelleyen sorgu hangisidir?

Cevap 44: UPDATE Ogrenciler SET Not_Ortalamasi = 4.00 WHERE Bolum = 'Elektronik';

Soru 45: Her bölümde okuyan öğrencilerin en düşük not ortalamasını gösteren sorgu hangisidir?

Cevap 45: SELECT Bolum, MIN(Not_Ortalamasi) FROM Ogrenciler GROUP BY Bolum;
